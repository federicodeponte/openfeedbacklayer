### Remaining blockers for 95+

**P0 — Ship-blocking**
1. **Rate-limit store is in-memory only** (`Map<string, {count, resetAt}>`). On serverless (Vercel), each invocation gets a fresh process → limit is trivially bypassed. Move to Redis or at least document this loudly in README as a known limitation with a Supabase-backed fallback.
2. **Screenshot upload has no file-type validation beyond `accept="image/*"`**. The server trusts `contentType: 'image/png'` from the client filename. An attacker can upload a `.png` that is actually HTML/JS and serve it from the Supabase public bucket as a stored-XSS vector. Verify magic bytes (`PNG` header) server-side before upload, or at minimum restrict to known-safe types.
3. **`getSupabaseAdmin` singleton caches the client across requests with `process.env`**. In long-lived containers this is fine; in serverless it's mostly fine, but if env vars rotate the cached client stays stale. Minor, but for 95+ use a factory or document it.

**P1 — Polishing**
4. **Build warnings**: tsup emits `Module level directives cause errors when bundled` for `"use client"` and `named and default exports together`. These are benign but noisy; fix with `tsup` `output.exports: "named"` and split widget entry.
5. **No retry/backoff on AI or email failures** — `analyzeFeedback` and `sendConfirmation` fail silently with `console.error`. For 95+ the server should at least return feedback to the user even if AI/email is down (it does), but the owner notification email is fire-and-forget with no dead-letter handling.
6. **Widget FAB is 48×48 but the popup is 320px fixed width** — on 320px-wide viewports (iPhone SE) it overflows. Add `max-width: calc(100vw - 24px)` and viewport-aware positioning.

**P2 — Nice to have**
7. **Missing `aria-live` on error/success states** — screen readers don't announce "We couldn't send..." or the success badges without it.
8. **No CSP nonce or `style-src` guidance** — the widget injects inline styles. Document a strict-CSP install path (e.g. `style-src 'self'` won't work out of the box).
